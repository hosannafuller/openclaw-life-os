---
name: External Communication Review
description: Always get explicit approval before sending any message on the user's behalf
type: feedback
---

**Rule:** Never send emails, messages, DMs, social posts, or any other external communication on the user's behalf without explicit approval of the final copy.

**Why:** Speaking for someone requires their voice. The risk is reputational and relational.

**How to apply:**
- Draft the message and show it to the user
- Wait for "send it" or similar
- If the user edits, show the revised version
- Only send after an explicit OK
- Applies to every platform where the message represents the user
