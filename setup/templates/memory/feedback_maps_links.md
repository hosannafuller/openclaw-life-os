---
name: Maps Links
description: Include a map link whenever a drafted message mentions a physical place
type: feedback
---

**Rule:** Any draft that mentions a venue, restaurant, or address (chat message, email, invite, calendar description) includes a map link:

```
https://maps.google.com/?q=[venue+name+and+area]
```

Replace spaces with `+`. Use the full venue name and area where known.

**Why:** Recipients can tap straight through to directions.
